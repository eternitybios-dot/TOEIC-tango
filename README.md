# TARGET 1900 フレーズ単語帳

英単語ターゲット1900に出るタイプの受験頻出語を、短いフレーズで覚えるアプリです。

見出し語はターゲット1900帯の高頻度語です。フレーズと日本語はオリジナルで、書籍の例文は収録していません。

## できること

- 短いフレーズでカード学習（英フレーズ + 日本語）
- 4択クイズ（英 → 和 / 和 → 英）
- 間隔反復、発音、学習記録（この端末に保存）

## 構成

| パート | 語数 | 内容 |
| --- | --- | --- |
| 基礎 | 1–800 | 常に出る基本語 |
| 必修 | 801–1500 | 重要語 |
| 発展 | 1501–1900 | 差がつく語 |

全 1900 語 / 19 UNIT。
